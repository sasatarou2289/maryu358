# AI Anime Video Maker 取扱説明書

`ai_video_maker.html` は、好きなテーマを入れて縦型AIアニメ風ショート動画の下書きを作るツールです。

怪談、学校ホラー、日常系、恋愛、ファンタジー、コメディなど、サロンやサービスに関係ない普通のアニメ動画にも使えます。

## できること

- 15秒 / 30秒の縦型動画を作る
- 横型16:9の動画も作る
- 最長30分までの長尺動画に対応
- ブラウザ上でアニメ風プレビューを再生する
- WebM形式で動画を書き出す
- Runway / Pika / Luma / Kling などに使えるプロンプトを作る
- CapCutで仕上げる前の下書き動画を作る

## 開き方

1. `sns_automation_app/ai_video_maker.html` をブラウザで開く
2. または `sns_automation_app/index.html` を開き、左メニューの `AI動画` を押す

## まず押す順番

最初はこの順番だけで大丈夫です。

1. `構成を生成`
2. `プレビュー再生`
3. `動画を書き出す`
4. `WebMを保存`

## 入力項目

### 動画テーマ

作りたい動画のタイトルや内容を入れます。

例:

```text
トイレの花子さんが放課後の学校に現れる怪談アニメ
```

### ジャンル・題材

動画のジャンルを入れます。自由入力できます。

例:

```text
怪談・学校ホラー
```

ほかにも以下のように使えます。

```text
日常系アニメ
ファンタジー冒険
恋愛ショート
ミステリー
コメディ
```

### 動画尺

作りたい長さを選びます。

- 15秒 / 30秒: TikTokやショート向け
- 1分 / 2分 / 3分 / 5分: 短い物語向け
- 10分 / 15分 / 30分: 長尺動画向け

長尺を選ぶと、約15秒ごとのシーンに分けて構成します。

### 画面比率

投稿先に合わせて選びます。

- 縦 9:16: TikTok、YouTube Shorts、Instagram Reels向け
- 横 16:9: YouTube通常動画向け

### あらすじ・起きること

動画内で起きる出来事を短く入れます。

例:

```text
放課後、誰もいない校舎のトイレから女の子の声が聞こえる
```

### ラスト・オチ

最後にどう終わるかを入れます。

例:

```text
振り向くと、鏡の中だけに花子さんが立っている
```

### アニメの雰囲気

絵柄、背景、色、怖さ、テンポなどを入れます。

例:

```text
昭和の学校、薄暗い廊下、少し怖いけど見やすい、2Dアニメ
```

## ボタンの意味

### 構成を生成

入力内容から、シーン構成・字幕・ナレーション・外部AI用プロンプトを作ります。

### プレビュー再生

右側の縦型キャンバスで、簡易アニメを再生します。

これは本格AI動画ではなく、流れや字幕を確認するための下書きプレビューです。

### 動画を書き出す

プレビュー動画を `WebM` 形式で保存できるようにします。

書き出しが終わると `WebMを保存` が表示されます。

### プロンプトをコピー

外部AI動画ツール用のプロンプトをコピーします。

Runway、Pika、Luma、Klingなどに貼り付けて、より本格的なAIアニメ動画を生成できます。

## トイレの花子さん動画の入力例

```text
動画テーマ: トイレの花子さんが放課後の学校に現れる怪談アニメ
ジャンル・題材: 怪談・学校ホラー
動画尺: 15秒
あらすじ・起きること: 放課後、誰もいない校舎のトイレから女の子の声が聞こえる
ラスト・オチ: 振り向くと、鏡の中だけに花子さんが立っている
アニメの雰囲気: 昭和の学校、薄暗い廊下、少し怖いけど見やすい、2Dアニメ
```

## 外部AI動画ツールで高品質化する場合

1. `構成を生成` を押す
2. `プロンプトをコピー` を押す
3. Runway / Pika / Luma / Kling などに貼り付ける
4. Scene 1、Scene 2 のようにシーンごとに生成する
5. 生成した動画をCapCutに並べる
6. 字幕、効果音、BGMを追加する
7. MP4で書き出す

## CapCutで仕上げる場合

1. 書き出したWebMをCapCutに読み込む
2. 怖い雰囲気なら、低めの環境音や足音を入れる
3. 字幕を見やすい位置に置く
4. 必要なら暗転、ズーム、効果音を追加する
5. MP4で書き出す

## 注意点

- 現在の書き出し形式は `WebM` です
- MP4にしたい場合は、CapCutに読み込んでMP4で書き出してください
- 10分以上の書き出しはブラウザが重くなる場合があります
- 30分動画はファイルサイズが大きくなるため、まず1分でテストしてから作るのがおすすめです
- このツール単体では、RunwayやPikaのような本格AI動画生成は行いません
- 本格AI動画にする場合は、生成されたプロンプトを外部AI動画ツールに入れてください
- 怖い動画を作る場合も、過度にグロい表現やショッキングな描写は避けるとSNS向けに使いやすいです
